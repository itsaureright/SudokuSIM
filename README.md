# PROJET DE SIM3 : SUDOKU

Ce programme a deux objectif : 

- Générer et résoudre des grilles de sudoku uniques, classiques ou diagonales, et de taille choisie.
- Jouer au Sudoku via une interface graphique, avec la possibilité de choisir son niveau de difficulté.

Les instructions pour utiliser le projet sont les suivantes :

- Compiler le projet en tapant "make" dans votre terminal.
- Executer le main grace à la commande "./output.main".
- Suivre les instructions qui apparaissent dans le terminal.

Attention, la création de la grille et lancement de l'interface graphique pouur le mode "jouer" peuvent prendre une dizaine de secondes.
Bon jeu !
